\section*{Supplementary Note 2: Mathematical Formulations for Spectral Biomarkers}

Each 4.0-second epoch $x(t)$ (1,024 discrete samples at 256 Hz) was evaluated for power spectral density (PSD) using Welch's modified periodogram method with a 1.0-second Hamming window and 50\% overlap:
\begin{equation}
P(f) = \frac{1}{K U} \sum_{k=1}^K \left| \sum_{n=0}^{N-1} x_k(n) w(n) e^{-j 2 \pi f n / f_s} \right|^2
\end{equation}
where $w(n)$ denotes the Hamming taper, $U = \frac{1}{N} \sum_{n=0}^{N-1} w^2(n)$ is the window normalization constant, and $K$ is the number of sub-segments.

Relative bandpowers were computed across five canonical EEG frequency ranges:
\begin{itemize}
    \item Delta ($\delta$): 0.5--4.0 Hz
    \item Theta ($\theta$): 4.0--8.0 Hz
    \item Alpha ($\alpha$): 8.0--13.0 Hz
    \item Beta ($\beta$): 13.0--30.0 Hz
    \item Gamma ($\gamma$): 30.0--45.0 Hz
\end{itemize}

Gaussian Differential Entropy (DE) for band-filtered signal $s(t) \sim \mathcal{N}(\mu, \sigma^2)$ is derived as:
\begin{equation}
h(S) = -\int_{-\infty}^\infty p(s) \ln p(s) \, ds = \frac{1}{2} \ln(2 \pi e \sigma^2)
\end{equation}
